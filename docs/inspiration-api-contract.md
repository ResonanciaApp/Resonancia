# Inspiración diaria — API contract

All routes below have `/api` prefix. All JSON/image responses are `Cache-Control: private, no-store`. Auth uses existing Clerk Bearer/cookie middleware; `/admin/*` requires `admin`. Public reading is free. Errors `{error:string, currentRevision?:number}`: 400 validation, 401/403 auth, 404 missing, 409 revision/date conflict. Never retry 409 by silently replacing revision.

## DTOs

- `InspirationContent`: `{quote:string, author:string|null, reflection:string, imagePath:string|null, imagePositionX:number, imagePositionY:number, overlayOpacity:number, sessionId:string|null}`. Positions 0..100 (default 50), opacity 0..0.85 (default .35). Quote max 2000, author 200, reflection 20000. Draft strings can be empty. `imagePath` is the opaque path returned by the dedicated upload endpoint, never an arbitrary URL. Public content replaces `imagePath` with `imageUrl` (absolute protected API URL); sessionId uses existing catalog/session player.
- `InspirationDay`: `{date:string, status:"available"|"future"|"unavailable", id:string|null, revision:number|null, content:InspirationPublicContent|null}`. Date is YYYY-MM-DD. Future/absent/unpublished rows have **null id/revision/content**. Saved unavailable items retain identity separately.
- `InspirationWeek`: `{weekStart:string,today:string,timeZone:string,days:InspirationDay[],settings:InspirationSettings}`. Exactly Monday–Sunday, seven positions. `date` selects any date in desired week. `timeZone` defaults UTC, must be valid IANA; today only comes from server clock.
- `InspirationSettings`: `{revision:number,sectionTitle:string,readMoreLabel:string,discoverMoreLabel:string,notesLabel:string}`. Spanish defaults. No editorial content seeded.
- `AdminInspiration`: `{id:string,date:string,revision:number,draft:InspirationContent,published:InspirationContent|null,publishedRevision:number|null,deleted:boolean,updatedAt:string}`. Stable UUID; date unique including tombstones. Editing draft does not change published snapshot. Moving an already-published date requires unpublish first.
- `AdminInspirationWeek`: `{weekStart:string,days:{date:string,inspiration:AdminInspiration|null}[],settings:InspirationSettings}`.
- `InspirationFavorite`: `{inspirationId:string,revision:number,deleted:boolean,updatedAt:string,day:InspirationDay|null}`.
- `InspirationNote`: `{id:string,inspirationId:string,text:string,revision:number,deleted:boolean,updatedAt:string,date:string|null}`. Owner determined exclusively by authentication. Note UUID generated by client; 1..20000 characters while live. Notes remain retrievable after editorial withdrawal/deletion.

| Method/path | operationId | Input → output |
|---|---|---|
| GET `/inspirations/week` | `getInspirationWeek` | query `date?`, `timeZone?` → InspirationWeek |
| GET `/inspirations/by-date/{date}` | `getInspirationByDate` | query `timeZone?` → InspirationDay |
| GET `/inspirations/{id}` | `getInspiration` | query `timeZone?` → InspirationDay (unknown ID 404) |
| GET `/inspirations/{id}/image` | `getInspirationImage` | query `timeZone?`, `revision?` → image bytes; denied for future/unpublished/stale revision |
| GET `/inspirations/settings` | `getInspirationSettings` | → InspirationSettings |

## Admin operations

| Method/path | operationId | Input → output |
|---|---|---|
| GET `/admin/inspirations/week` | `getAdminInspirationWeek` | query `date?` → AdminInspirationWeek |
| GET `/admin/inspirations/{id}` | `getAdminInspiration` | → AdminInspiration |
| POST `/admin/inspirations` | `createAdminInspiration` | `{date,draft}` → AdminInspiration |
| PUT `/admin/inspirations/{id}` | `updateAdminInspiration` | `{revision,date,draft}` → AdminInspiration |
| POST `/admin/inspirations/{id}/publish` | `publishAdminInspiration` | `{revision}` → AdminInspiration |
| POST `/admin/inspirations/{id}/unpublish` | `unpublishAdminInspiration` | `{revision}` → AdminInspiration |
| DELETE `/admin/inspirations/{id}` | `deleteAdminInspiration` | JSON `{revision}` → AdminInspiration tombstone |
| PUT `/admin/inspirations/settings` | `updateInspirationSettings` | full InspirationSettings incl revision → InspirationSettings |
| POST `/admin/inspirations/uploads` | `requestInspirationUpload` | `{name,size,contentType}` → `{uploadURL,objectPath}` |
| GET `/admin/inspirations/image` | `getAdminInspirationImage` | query `objectPath` → bytes (admin preview; attach authorization; do not use raw storage URL) |

Images JPEG/PNG/WebP, max 15 MiB; upload through returned PUT uploadURL, then save objectPath. Publish validates actual object existence/size/MIME/signature. Assets are private and generic storage routes cannot serve inspiration assets. Images are not removed on replacement; shared references are retained.

Image validation fully decodes static images (up to 25 megapixels, each edge at most 10000px). Publication pins the storage object generation; a surviving PUT URL cannot replace published bytes. A changed upload must be uploaded again using a fresh URL/path. A deleted editorial record reserves its date/UUID and appears as `deleted:true` in Admin; to recreate that day use PUT with its current revision (restores a draft with the same identity), not POST. Public image URLs resolve the existing trusted proxy host/protocol for native clients.

## Owner-only sync operations

| Method/path | operationId | Input → output |
|---|---|---|
| GET `/me/inspiration-favorites` | `getInspirationFavorites` | query `timeZone?` → `{items:InspirationFavorite[]}` including tombstones |
| PUT `/me/inspiration-favorites/{inspirationId}` | `putInspirationFavorite` | `{revision,deleted}` → InspirationFavorite |
| GET `/me/inspiration-notes` | `getInspirationNotes` | query `inspirationId?` → `{items:InspirationNote[]}` including tombstones |
| PUT `/me/inspiration-notes/{id}` | `putInspirationNote` | `{revision,inspirationId,text,deleted}` → InspirationNote |

Private PUTs use revision 0 to create and current server revision to change. Unknown-item deletion creates a tombstone. Repeating the exact current state with its immediately previous revision is an idempotent retry. Other stale writes return 409 with currentRevision; preserve local text for explicit resolution. Once deleted a note UUID cannot be restored (create a fresh UUID); favorites may be restored only with the current tombstone revision. Favorite creation and live note creation require an available inspiration (`timeZone` query accepted by both PUTs); existing notes can still be edited after withdrawal. Removal always allowed. Tombstones are permanent until account deletion. No bulk replacement endpoint. Lists/export include only the authenticated owner's data, never admin bypass.

Existing `/me/export` includes `inspirationFavorites` and `inspirationNotes`; account deletion cascades them. Guest persistence/import confirmation and offline queue belong to Mobile. React Query hooks are Orval's standard `useGet…` / `usePut…`, etc.; shared generated functions have exact operationIds above.

---
name: Hero secundario en Admin Inspiración
description: Jerarquía visual del editor Hero de Inicio dentro de Sabiduría diaria.
---

El editor “Hero de Inicio” es una opción secundaria: debe vivir debajo del selector semanal y del editor diario, plegado por defecto con su estado visible. No debe ocupar una tercera columna ni reducir el ancho de las áreas principales.

**Why:** El bloque abierto como tercera columna ocupaba demasiado espacio y comprimía el selector y el editor de Sabiduría diaria, que son las tareas principales de esta pantalla.

**How to apply:** Mantener sus controles completos dentro del desplegable. Si se amplía su funcionalidad, conservar el resumen compacto y evitar que compita horizontalmente con el editor diario.

---
name: Afinidad emocional de sesiones
description: Contrato editorial para asociar sesiones a emociones y construir las cinco recomendaciones del cierre.
---

Las sesiones guardan IDs estables de emoción, no emojis ni etiquetas visibles. El cierre emocional conserva cinco slots en este orden: meditación, música, sonoterapia, reflexión e historia. Dentro de cada slot gana la sesión con más coincidencias explícitas y no se repiten sesiones.

**Why:** Las categorías y etiquetas temáticas eran una aproximación indirecta y podían recomendar contenido poco relacionado. Los IDs estables permiten control editorial sin depender del texto o emoji mostrado.

**How to apply:** Mantener sincronizado el conjunto canónico de 18 IDs entre contrato, Admin y móvil. Al ampliar o repoblar el catálogo, asegurar al menos una sesión elegible por emoción en cada slot; las cinco reservas base solo cubren huecos.

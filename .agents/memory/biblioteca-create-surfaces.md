---
name: Fondos de creación en Biblioteca
description: Elección visual deliberada para las ventanas de creación de Biblioteca.
---

Las ventanas de crear carpeta y playlist de Biblioteca, incluidas las variantes de carpeta de Favoritos y Mezclas, y el menú del botón + usan un fondo sólido del último stop del tema activo, no un degradado.

**Why:** Se probó un fondo con los tres últimos stops y el usuario pidió expresamente reemplazarlo por solo el último. Es una excepción intencional a cualquier regla general de degradados para ventanas.

**How to apply:** Mantener esta elección al modificar las superficies de creación de Biblioteca; no extenderla automáticamente a otros modales.
